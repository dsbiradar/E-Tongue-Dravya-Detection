How It Works

From Sensor to Prediction

The E-Tongue system mimics biological taste perception — converting chemical properties of liquid Dravya samples into a machine-readable feature vector for instant ML classification.

Three electrochemical sensors — pH, TDS (Total Dissolved Solids), and EC (Electrical Conductivity) — are immersed in a liquid Dravya sample. Each sensor produces a voltage reading proportional to the ionic composition of the solution.

These readings are captured by an Arduino microcontroller at 9600 baud, streamed over serial USB, and parsed by a Python backend in real time.

A trained Random Forest classifier receives the three-dimensional feature vector (pH, TDS, EC) and outputs both the predicted Dravya class and per-class probability scores within milliseconds.

1

Sample Immersion

Sensors are dipped into the prepared Dravya liquid — leaf extract, bark decoction, or juice.

2

Arduino Data Capture

pH, TDS, and EC analog signals are digitized and transmitted via serial at 9600 baud.

3

Flask Serial Parser

Python parses and validates incoming serial lines, filtering out noise and malformed packets.

4

Random Forest Inference

The trained model predicts the Dravya class and outputs confidence probabilities for each class.

5

WebSocket Broadcast

Results are emitted via Socket.IO to the dashboard in real time with zero page reload.

Machine Learning

Random Forest Classifier

Chosen for its robustness with small sensor datasets, built-in feature importance, resistance to overfitting, and native probability output per class.

Ensemble of Decision Trees

Aggregates predictions from multiple trees, reducing variance and producing stable classifications even with noisy sensor data.

Real-Time Inference

Sub-millisecond prediction latency on CPU — no GPU needed. The trained joblib model loads once at startup and serves every incoming reading instantly.

Probability Output

Returns confidence percentages for Karanda, Neem, and Tulsi simultaneously — enabling the dashboard to display ranked probability bars.

3-Feature Input Vector

Input: [pH, TDS, EC]. Each Ayurvedic herb exhibits a chemically distinct signature across these three electrochemical axes, making them naturally separable.

Robust to Sensor Noise

Majority voting across trees naturally suppresses outliers from sensor fluctuations — no preprocessing smoothing required at inference time.

Serialized with Joblib

Trained model saved as best_dravya_model.pkl using joblib for efficient loading. No retraining needed between server restarts.

Why Random Forest?

With only three input features and a small labeled dataset of Dravya sensor readings, Random Forest delivers optimal performance — handling non-linear decision boundaries between Dravyas that simpler classifiers like logistic regression struggle with. It also provides built-in feature importance ranking, helping verify that the sensor data is physiochemically meaningful.
